# Praveesh Portfolio

## Run locally

```sh
npm ci
npm run dev
```

## Production

```sh
npm run build
npm run preview
```

Deploy the generated `dist/` directory.

## Portfolio redesign

The redesigned entry point is `index.html`, with `styles.css`, `redesign.css`, and `app.js`. It uses plain HTML/CSS/JavaScript through the existing Vite build. Original React source remains under `src/` for reference and is not the active entry point.

Assets, font licenses, and the downloadable resume are in `public/portfolio-assets/`. The site includes the 60–30–10 palette, IsItOutYet as the featured project, repository links, and the updated Codecraft/Incture career history. Contact opens a prefilled email draft.

No Sites credentials or deployment metadata are included.
