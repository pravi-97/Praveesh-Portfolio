FEATURED PROJECT · FULL STACK

IsItOutYet?

Stop checking. Start following.

I built IsItOutYet after repeatedly missing TV episodes because release schedules changed or shows quietly returned. It brings show discovery, personal tracking, and release notifications together.

What it does

  • Search for shows and maintain a personal watchlist.
  • Discover trending shows and shows airing today.
  • Receive notifications for new episode or season releases.

Built with

React and Vite on the frontend; Java and Spring Boot on the backend, with PostgreSQL persistence and Firebase authentication.
